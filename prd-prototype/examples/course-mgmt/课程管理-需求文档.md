## 1 概述

### 业务背景

高校教务处每学期要整理一次开课课程目录，目前在 Excel 里维护。新增课程后，教务员要手工核对学院、学分和课程代码，经常漏填或重号。本期在教务管理台做一个课程列表页：能按名称或代码找课，能新增课程并在提交前拦住漏填，提交失败时保留已填内容。 【AI 假设】

### 建设目标

- 教务员在一个列表里找到本学期全部开课课程 【AI 假设】
- 新建课程时，必填项和长度错误在提交前拦住，不发出请求 【AI 假设】
- 提交失败后不需要重新填写，原内容保留，可直接重试 【AI 假设】

### 本期范围

| 端 | 模块 | 页面 |
| --- | --- | --- |

**明确不做**

- 排课、选课、成绩等教务模块 【AI 假设】
- 课程编辑、停用与删除：本期只新增与查看 【AI 假设】
- 导入、导出 Excel 【AI 假设】
- 多学期切换：页面固定显示 2026–2027 学年第一学期 【AI 假设】

### 教务管理台

#### P01 课程管理 

- **页面目标**：教务处课程管理员查看本学期全部开课课程，按名称或代码找课；新增一门开课课程，提交前拦住漏填，提交失败时保留已填内容并可重试；查看单门课程的详情。 【AI 假设】
- **入口与前置**：顶部导航“课程管理”，默认首页 【AI 假设】
- **角色权限**：教务处课程管理员（本画面为管理员视角）；学院教学秘书只读，看不到“新建课程”按钮 【AI 假设】

**页面状态**

| 状态 | 出现条件 |
| --- | --- |
| 课程列表 | 进入页面；新增成功、点“取消”、关闭详情抽屉后回到列表。演示数据中本学期有开课课程（默认 9 门） |

| 课程详情抽屉 | 在列表某一行点“详情” |

**功能点**

##### ① 课程搜索 `filter`【AI 假设】

在搜索框输入课程名称或课程代码，列表立即只保留包含这些文字的行（不区分大小写）。没有匹配的课程时，列表区域显示“没有匹配的结果”。清空搜索框后恢复全部课程。原型限制：只在第 1 页的 10 行中匹配。

| 字段 | 类型 | 必填 | 默认值 | 可选值 | 规则与口径 |
| --- | --- | --- | --- | --- | --- |
| 搜索关键词 `kw` | 文本 | 否 |  |  | 匹配课程名称或课程代码，包含即命中；不区分大小写；最多 30 字 |

**规则**

- 列表内容随输入实时筛选（匹配列表行中的文字），无匹配项时显示“没有匹配的结果”

<small>出现在：课程列表</small>

##### ② 开课课程列表 `table`【AI 假设】

列表按数据顺序显示，新增成功的课程排在最前。每行显示课程代码、课程名称、开课学院、学分、任课教师和状态。点行尾“详情”，打开该课程的详情抽屉。

| 课程名称 `name` | 文本 | 否 |  |  | 新建时填写，2–30 字 |
| 开课学院 `college` | 枚举 | 否 |  | 计算机学院、外国语学院、经济管理学院 |  |
| 学分 `credit` | 数字 | 否 |  |  | 1–4 的整数 |
| 任课教师 `teacher` | 文本 | 否 |  |  | 新增课程默认“待指定”，本页不修改 |
| 状态 `status` | 枚举 | 否 |  | 待排课、已发布 | 新增课程默认“待排课” |

**空数据**：本学期还没有开课课程：列表区域显示“本学期暂无开课课程”，并给出“新建课程”按钮

<small>出现在：课程列表</small>

##### ③ 分页计数 `pager`【AI 假设】

每页 10 条。课程不足 10 条时只显示“共 N 条”；10 条及以上时显示页码和“第 X~Y 条 / 共 N 条”。搜索后，计数和页码按匹配的结果计算，匹配超过 10 条时可以翻页。原型限制：原型只展示第 1 页，搜索时计数不变；翻页按钮只作展示。

<small>出现在：课程列表</small>

##### ④ 新建课程入口 `create-entry`【AI 假设】

点“新建课程”，在列表上方弹出新建弹窗，列表保持在背后，不离开页面。

<small>出现在：课程列表</small>

##### ⑤ 新建课程表单 `create-form`【AI 假设】

弹窗里填写课程代码、课程名称、开课学院、学分和备注。提交前校验必填项和长度，不通过的字段在下方提示原因。

| 字段 | 类型 | 必填 | 默认值 | 可选值 | 规则与口径 |
| --- | --- | --- | --- | --- | --- |
| 课程代码 `no` | 文本 | 是 |  |  | 6–12 位字母或数字；同一学期内唯一 |
| 课程名称 `name` | 文本 | 是 |  |  | 2–30 字 |
| 开课学院 `college` | 枚举 | 是 |  | 计算机学院、外国语学院、经济管理学院 |  |
| 学分 `credit` | 数字 | 是 |  | 1、2、3、4 | 整数，1–4 学分 |
| 备注 `note` | 文本 | 否 |  |  | 选填，最多 200 字 |

**规则**

- 课程代码为必填项，为空时不能提交
- 课程代码长度为 6–12 个字，不在此范围内时不能提交
- 课程名称为必填项，为空时不能提交
- 课程名称长度为 2–30 个字，不在此范围内时不能提交
- 开课学院为必填项，为空时不能提交
- 学分为必填项，为空时不能提交
- 备注最多 200 个字，超出时不能提交

<small>出现在：新建课程弹窗</small>

##### ⑥ 提交新建课程 `submit`【AI 假设】

点“提交”：先校验，不通过则不发出请求。通过后提交，成功则关闭弹窗，课程插入列表最前，分页计数加 1。点“取消”关闭弹窗，已填内容不保留。

**规则**

- 提交前先校验必填项和长度，不通过时在字段下方提示，不发出请求
- 提交中按钮禁用，重复点击只提交一次
- 提交失败时保留已填内容并提示，可直接重试（可在数据场景中切换，演示首次提交失败）
- 提交成功后在「开课课程列表」中新增一条，进入「课程管理」

**异常与边界**

- 必填项为空或长度不对：不发出请求，字段下方提示原因，表单顶部提示“有 N 项需要修改”
- 提交失败（网络异常）：保留已填内容，表单顶部提示“提交失败，网络异常”，可直接再次点“提交”
- 提交中：提交按钮显示“提交中…”并禁用，重复点击只提交一次
- 课程代码与本学期已有课程重复：服务端拒绝提交，保留已填内容，表单顶部提示“课程代码已存在”，修改课程代码后可再次提交。原型不演示此分支

<small>出现在：新建课程弹窗</small>

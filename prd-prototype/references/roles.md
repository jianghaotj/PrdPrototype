# 按角色看原型

同一张原型里，不同角色该看到的按钮不一样。功能点可以写 `roles`，查看器顶栏用角色下拉过滤。

## 怎么写

在功能点上加可选字段：

```js
{ id: 'create-entry', name: '新建课程入口', roles: ['admin'], /* … */ }
```

- `roles` 是角色 id 数组，必须能在 `product.roles` 里找到。
- 不写，或写空数组：所有角色都看得到。
- 页面上的 `perm` 仍是给人看的文字，不参与过滤。

## 查看器

产品声明了 `product.roles` 时，顶栏出现角色下拉，多一个「全部角色」。

选中某个角色后：

- 需求面板里不属于该角色的功能点卡片会隐藏；
- 画板上对应的编号圆点会隐藏；
- 画板元素也会隐藏：原生页面按 `[data-fn]`，托管页面按功能点的 `sel`。

当前角色记在浏览偏好里（和热区、圆点那些一样），刷新后还在。原型阶段同样可用（没有需求面板时，只过滤圆点和画板元素）。

## 构建检查

`ROLE_ID`：功能点的 `roles` 引用了未声明的角色，或 `product.roles` 为空却写了 `fn.roles`。会阻止交付。说明见 `audit-codes.md`。

当前不会按每个角色重跑一遍覆盖率；过滤只发生在查看器里。

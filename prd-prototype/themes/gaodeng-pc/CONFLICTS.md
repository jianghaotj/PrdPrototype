# gaodeng-pc 冲突清单

范围：规范包 `gaodeng-pc` 的修正记录，以及需要设计组确认的条目。
依据：高教 PC 设计规范（Web 2.0.1）的 PDF 与其文字版，两者都不入库。文字版没有版面信息，凡是需要看版面才能判断的，都标为待确认。
章节号（如 [6.5]）指规范目录的编号。本文件只概括冲突点，不引用规范原句。

## 三、删除或降级的内容

| 原包内容 | 处理 | 理由 |
|---|---|---|
| §11 "16px Medium 白字可接受" | 删除 | 16px 不是大字，正文文字需 4.5:1，白字压 `#5C8AFF`（3.21）不达标 |
| §11 "≥18px 文字可用 LV3 或悬停色" | 删除 | 18px 不是大字（大字为 24px 常规或约 18.7px 粗体） |
| §11 "Medium 算粗体" | 删除 | WCAG 中粗体按 700 理解，Medium(500) 不计入 |
| tokens `--surface-2`（`#EEF1F6`） | 删除 | 规范背景只有三档，原包自己也写"规范未登记" |
| tokens `--leading-display`（1.4）、`--leading-single`（1）、`--leading-single-extra`（8px） | 删除 | 单行行高按字号表给出（字号加 8px）。1.2 节提到过单倍行高，但字号表里没有对应档，所以不设 token |
| tokens `--container`（1200px，全局） | 改为 `--container-w`，并注明只适用于上中下布局 | 见第一节第 4 条 |
| DESIGN §1、§9 "一屏只允许一个主按钮"、"一屏不超过两处大面积品牌色" | 保留，标为 `[AI 假设]` | 规范原文没有这些条文 |
| DESIGN §3 "上限 1.7 倍"、"中文标题字距 0" | 删除 | 规范没有这些条文 |
| DESIGN §12 间距 | 保留，标为 `[AI 归纳]` | 规范没有间距章节，由高频值归纳 |

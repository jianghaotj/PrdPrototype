# 高等设计组件库（gaodeng-pc）

来源：高等教育事业部设计组《设计规范》Web 2.0.1。PDF 原文未随仓库提供。下文的章节号（如 [6.5]）指规范目录。
冲突和待确认项见同目录的 `CONFLICTS.md`。与规范原文冲突时，以原文为准。
画板基准：1440×900，1 个 CSS px 等于 1 个设计 px。

标记：未标记的条文为规范原文或直接转述。`[补齐]` 表示规范未登记的派生值。`[AI 假设]` 表示规范没有依据的规则。`[AI 归纳]` 表示由规范多处高频值归纳。`[非原文，见 §11]` 表示本包的补充限制。`[待确认]` 表示原文有冲突或不清楚，见 CONFLICTS.md。

## 1. 视觉基调 [1.1、1.3]

后台产品的调性是信息优先，层级靠字重和灰阶区分，不靠装饰。`[AI 假设]`

- 内容区用白色（`--bg`）。LV6 浅灰（`--surface`）用于表头底，以及表格和列表的分割线。高亮底（`--accent-weak`）用于鼠标经过和选中行。
- 文字四级（LV1–LV4）。规范没有第五级灰。
- 描边 1px。强分割线和边框用 LV5，表格和列表的普通分割线用 LV6 [1.1]。
- 阴影有中阴影（卡片）和大阴影（弹窗、Tips）两档 [1.3]。6.8 另有一组卡片阴影，见 C4。
- 标签页下划线 [6.6] 为 2px，这是规范明确给出的例外。
- `[AI 假设]` 一屏大面积品牌色不超过两处，禁止渐变、毛玻璃。规范没有这些条文，只作为审校时的参考。

## 2. 色彩 [1.1]

| 名称 | 值 | 用途 |
|---|---|---|
| 文字 LV1 | `#1A2233` | 标题、正文主色 |
| 文字 LV2 | `#575C66` | 次级正文、表格行内容 |
| 文字 LV3 | `#858C99` | 解释说明文案、中性图标 [1.1]。作小字时用 `--fg-3-ink`，见 §11（`[非原文，见 §11]`，C20） |
| 文字 LV4 | `#C2C5CC` | 最次级文案、不可点文字 |
| 强分割线 LV5 | `#E1E6F0` | 强分割线（如表头下方）、边框色 [1.1] |
| 背景 LV6 | `#F5F7FA` | 表头背景、表格和列表分割线 [1.1] |
| 品牌 | `#3264FA` | 默认：主按钮、强调文字、当前项 |
| 品牌悬停 | `#5C8AFF` | 悬停：描边、图标、带交互文字的颜色，主按钮底也用此值（见 §11、C12） |
| 品牌不可点 | `#ADCAFF` | 不可点 |
| 高亮底 | `#F0F6FF` | 鼠标经过、表格选中行 [6.5] |
| 导航悬停底 | `#F2F5FF` | 待确认（C13），用途存疑 |
| 题库蓝 | `#D6E5FF` | 业务专用，题库类背景 [1.1 LV3-2] |
| 成功 / 危险 / 警告 | `#0AC77C` / `#FF6859` / `#FF8000` | 语义色。`#FABE0A` 仅配深色字 `[AI 假设]`，见 C21 |

- 悬停色和不可点色是规范给定值，不要自行调浅调深。
- `#E6ECFF`（`--accent-weak-2`）原文用途不清，只在 tokens 中保留，见 C13。
- 图标悬停用 `#5983FF`（[2.1] 图标），与控件悬停 `#5C8AFF` 不同，规范即如此（C11）。
- 语义色须配文字或图标 `[AI 假设]`，见 C21。

## 3. 字体与字号 [1.2]

字体：中文与数字用苹方，英文用 Helvetica。优先级：苹方 → 微软雅黑；Helvetica → Arial。

| 字号 | 字重 | 用途（按规范文字页） |
|---|---|---|
| 28px | Medium | 页面核心强调 |
| 24px | Medium | 单个模块强调（C2） |
| 20px | Medium | 模块标题文案（C2） |
| 18px | Medium | 模块标题、一二级分类导航标题、列表标题（C2） |
| 16px | Medium / Regular | 标题、主操作按钮文案（C1） |
| 14px | Medium / Regular | 正文、按钮文案（C1） |
| 12px | Regular | 弱化内容、弱辅助文案、注释、次要信息 |

- 行高：单行文案为字号加 8px（规范表：12/20、14/22、16/24、18/26、20/28、24/32、28/36）。多行正文为 1.5 倍。
- 段间距与行间距的比例，原文表述不清，本包不规定具体值（C23）。
- 标题用 Medium(500)，正文用 Regular(400)。规范中的"加粗"按 Medium 理解（C19）。不用 700 制造层级（待确认 C19）。

## 4. 圆角与描边 [1.4、6.4]

- 4px：按钮、选择器、输入框、表单 [1.4]。
- 8px：对话框、通知提醒框 [1.4]。
- 2px：标签 [6.4]。异形分类标签的 4px / 1px 圆角待确认（C6）。
- 描边 1px。描边色用 LV5，或线性按钮用品牌色。
- 按钮圆角统一为 4px，不做胶囊形 `[AI 假设]`。2.2 另有直角、大圆角两个按钮页，是否为其他形态待确认（C22）。规范的胶囊样式出现在标签页 [6.6]，圆角 4px。

## 5. 阴影 [1.3]

| 档位 | 参数 | 用途 |
|---|---|---|
| 中阴影 | `#1A1F33`，10%，X 0、Y 4、模糊 12、扩展 -2 | 卡片（6.8 另有一组，见 C4） |
| 大阴影 | 规范只说明沿用 Ant Design 的数值，并把 #000 换成 #1A2233，未列具体数值。具体数值为 `[补齐]` | Tips、弹窗（C16） |
| 固定区投影 | `0 0 8px 0 rgb(225 230 240 / 30%)` | 弹窗内固定区滚动时 [7.1] |

- 卡片不叠多层阴影。`[AI 假设]`

## 6. 控件尺寸 [2.2、5.x]

三档高度，跨组件统一：

| 高度 | 场景 | 字号 | 最小宽 | 含图标最小宽 | 图标 |
|---|---|---|---|---|---|
| 40px | 页面中 | 16px | 86px | 106px | 18×18 |
| 32px | 弹窗、表格内 | 14px | 72px | 84px（C18） | 16×16 |
| 24px | 小范围辅助操作，如复制 | 14px | 54px | — | 14×14 |

- 按钮文案为两个字时，两字之间留一个空格 [2.2]。
- 按钮组合：主按钮在右，按钮间距取 8 的倍数 [2.2]。
- 输入框内边距：40/32px 为 12px，24px 为 8px [5.6 图注]。
- 下拉弹窗最大高度 320px，超出后内部滚动 [5.8]。
- 小按钮高度图注为 24px，正文为 28px，本包取 24px（C10）。

## 7. 表格 [6.5]

- 默认单元格高度 54px。40px 只用于对话框内。
- 表头：背景 LV6，14px Medium，文字 LV1。表头底部为 LV5 强分割线。
- 行内容：14px，LV2，左对齐。行间分割线为 LV6 [1.1]。
- 被选中行：`#F0F6FF`（规范标注为 LV4，色值与该档不符，见 C8）。
- 默认一页 10 行。不足 10 行时隐藏页码。带输入操作的表格用滚动，不分页。
- 单元格为空时显示 `-`。整张表没有数据时，改用缺省页（§9）。
- 表格中的时间、状态、操作列保持词语完整，不断行 [6.5]。

## 8. 布局与导航 [3.2]

布局章节按目录编为 3.2。规范的页内标题对布局的章节号写法与目录不一致，以目录为准，见 CONFLICTS 一、第 10 条。

- 画板 1440×900。主流分辨率为 1920、1440、1366，少数为 1280。
- 顶部导航（常规）：一级 64px，二级 40px。
- 顶部导航（展示类页面）：一级 80px，二级 48px。
- 导航高度公式为 48 + 8n，侧边导航宽度公式为 200 + 8n。二级 40px 不在公式之内，待确认（C9）。
- 内容宽度按布局区分，不是一律 1200px：
  - 上中下布局：内容放在固定宽度内，原文示例为 1200px，居中。
  - 顶部侧边布局：分两种。展示类网站页面居中，宽度原文未给。应用型网站两边不留边距。这两种的依据是原文图示 2.1、2.2，图示编号不是章节号。
  - 侧边布局：内容随浏览器宽度自适应。
- 水平分割线上下留 16px；带文字的分割线左右留 8px [3.1]。
- 移动端尺寸（375×812）在表格说明中出现，判断为版面残留，本包只覆盖 PC（C14）。

## 9. 组件使用边界

- 图标：中性场景用 LV3，可操作场景用品牌色。悬停用 `#5983FF` [2.1 图标]。
- 按钮：`[AI 假设]` 一屏只放一个主按钮。次要操作用线性按钮。破坏性操作才用危险色。
- 标签页、步骤条：当前项用品牌色加 Medium，其他项用 LV2 [6.6、4.3]。
- 缺省页 [6.3]：由图形、标题加副标题、引导按钮组成。引导按钮是下一步操作的入口，页面必须有。
  - 空白类：暂无数据、搜索无结果、暂无通知等。
  - 信息类：内容已删除、无权限等。
  - 系统类：加载失败、网络异常等。系统类可以只给一句原因，不展示返回码。
- 对话框 [7.1]：宽 480 / 640 / 720 / 960px，高 220 至 640px，头部 56px，内容区最小 60px，圆角 8px。遮罩 `#1A2233` 64%。取消在左、确认在右 [7.1 示例]。内容超过 640px 时，头部和底部固定，中间滚动。
- 警告提示 [7.2]、全局提示 [7.4]：全局提示顶部水平居中，默认 3 秒后消失。

## 10. 禁止事项

- 不混用规范外的灰阶或自定义品牌色深浅。
- 不用 700 或 800 字重代替字号层级 [待确认 C19]。
- 卡片不叠阴影，不加渐变。`[AI 假设]`
- 圆角按用途分开：卡片 8px [待确认 C5]，控件 4px。两者不互相替代。
- 表格不用 54px 行高挤进对话框。
- 空单元格用 `-`。整表无数据用缺省页 [6.3]，不用省略号或"暂无"文字占位。

## 11. 对比度（非原文补充）

规范原文没有对比度要求。本节由本包补充。下表数值是按 WCAG 2.x 公式计算的，四舍五入到两位小数。判断标准：正文需达到 4.5:1；大字（24px 常规或约 18.7px 粗体）需达到 3:1。规范的 Medium（500）不算粗体，所以 18px Medium 不是大字。图标和描边需达到 3:1。

| 规范原值 | 白底对比 | 允许的用法 | 不允许的用法 |
|---|---|---|---|
| LV3 `#858C99` | 3.38（LV6 底 3.15） | 图标、描边、≥24px 文字 `[非原文，见 §11]` | 12–18px 文字。小字用 `--fg-3-ink`（`#656C7A`，白底 5.28）（C20） |
| 品牌悬停 `#5C8AFF` | 3.21（LV6 底 2.99） | 白底上的描边、图标、≥24px 文字 | LV6 底上的描边和图标（2.99 低于 3:1）；16–18px 文字；白字压此底（C12） |
| 成功 `#0AC77C` | 2.22 | 装饰性填充，且必须配文字或图标 | 文字；白字压此底。小字用 `--success-ink`（`#07784C`，白底 5.53） |
| 危险 `#FF6859` | 2.85 | 同上 | 文字。小字用 `--danger-ink`（`#C62F20`，白底 5.49） |
| 警告 `#FF8000` | 2.52 | 同上 | 文字。小字用 `--warn-ink`（`#B05600`，白底 5.03） |
| LV4 `#C2C5CC` | 1.73 | 不可点状态 | 可读文字。占位符是否豁免见 C24 |

达标的组合：

- LV1 `#1A2233` 白底 15.90，LV2 `#575C66` 白底 6.71。
- 品牌 `#3264FA` 白底 4.84。白字压品牌底 4.84，可用于所有字号。
- 危险实心按钮底 `--danger-fill` `#C62F20`，白字 5.49。

实心按钮上的文字只用白色（`--accent-on`）。不要用白字压成功、警告、危险的原色。

以下为本包删除的说法，原包有、规范没有、计算也不成立：

- "16px Medium 白字可接受"。
- "≥18px 文字可用 LV3 或悬停色"。18px 不是大字。
- "Medium 算粗体"。

## 12. 间距 [AI 归纳]

规范没有间距章节。正文反复出现 4、8、12、16、24、32、40、48，并要求间距取 8 的倍数。tokens 中的 `--sp-*` 由这些值归纳而来。4px 只用于图标和文字之间的贴合间距，其余用 8 的倍数。
